# Ozy's Personal Website

🌐 **Live Demo:** [https://jlu005807.github.io/](https://jlu005807.github.io/)

This is Ozy's personal homepage, customized from the [HTML5 UP Massively](https://html5up.net/massively) template. It showcases personal projects, study notes, and interests. Feel free to visit the live site above!

## Features
- Personal introduction and skills
- Project and study showcase
- Life and interests sharing
- Smooth page transition animation
- Responsive design for mobile and desktop

## Tech Stack
- HTML5 & CSS3
- JavaScript (with jQuery)
- Responsive design
- [HTML5 UP Massively](https://html5up.net/massively) template

## How to Preview Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/jlu005807/jlu005807.github.io.git
   ```
2. Open `index.html` directly in your browser.

> For a better local experience, use VSCode Live Server or Python's simple HTTP server:
> ```bash
> python -m http.server 8000
> ```
> Then visit http://localhost:8000
