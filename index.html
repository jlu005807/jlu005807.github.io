🎮 Game Introduction

Tic-Tac-Toe is a classic two-player game played on a 3x3 grid. The first player to align three marks horizontally, vertically, or diagonally wins. If all 9 squares are filled with no winner, the game ends in a draw.

🕹️ How to Play

  • 🤖 AI mode: Challenge the computer with two difficulty levels: Easy and Hard.
  • 🖱️ Simple controls: Just click on the squares to make your move.

CPU Design

A CPU design project, including MIPS32 and LA32R implementations.
Download the files to learn more.

🖥️ Project Introduction

This project focuses on CPU design, featuring both MIPS32 and LA32R architectures.

Note: The MIPS32 and LA32R implementations have only passed their respective Lab1. The design includes BTB (Branch Target Buffer) and BHT (Branch History Table) for branch prediction, and uses bypass forwarding to resolve data hazards.

🔑 Key Features

  • 📊 Architecture comparison: MIPS32 and LA32R implementations.
  • 📄 Design documents: Detailed documentation for each architecture.
  • 🔗 PDF downloads: Downloadable resources for in-depth study.
  • 💡 Educational value: Suitable for learning CPU design principles.

KB-CLI

KB-CLI

A Rust CLI for local-first knowledge bases, layered memory, and pluggable Agent integration.

🧠 Project Introduction

KB-CLI is a Rust-based local knowledge base command-line tool with a six-layer memory architecture and a pluggable Agent memory system.

✨ Core Features

  • 🗂️ Local-first storage: Store data in JSON or SQLite locally for privacy and control.
  • 🧠 Layered memory: Organize knowledge from the raw timeline through indexes, search, graphs, and wiki content.
  • 🔌 MCP integration: Expose eight tools for Agent memory workflows through Model Context Protocol.
  • 🛡️ Grounded recall: Combine lexical validation, user corrections, and provenance chains to reduce hallucinations.
  • ⚡ Lightweight runtime: Run as a single binary without a vector database dependency.

🔌 MCP Integration

Run kb serve --mcp to expose the memory service to compatible Agents. Available tools include:

recall, remember, correct, verify_citation, list_episodes, consolidate, read_summary, and read_neighbors.

🚀 Quick Start

kb init my-kb
cd my-kb
kb add test.md
kb update
kb ask "What is in the test document?"
kb remember "This is a test project"
kb consolidate

For detailed information, please check the GitHub repository: https://github.com/jlu005807/Kb-cli

CppPools

CppPools

A C++17 concurrency project connecting ThreadPool, ObjectPool, and DBConnectionPool through a Socket HTTP service.

🏗️ Project Introduction

CppPools is a minimal runnable project for concurrency learning and interview demonstrations. It combines C++17, a self-built Socket-level HTTP/1.1 server, MySQL support, and three cooperating resource pools.

🏊 Pooling Architecture

  • 🧵 ThreadPool: Fixed workers, a producer-consumer queue, futures, and safe shutdown.
  • 🧰 ObjectPool: Pre-created or on-demand RequestContext objects returned automatically through RAII.
  • 🗄️ DBConnectionPool: Bounded connection acquisition with timeouts and DBConnGuard for automatic release.

HTTP request -> ThreadPool -> ObjectPool -> DBConnectionPool -> JSON response

🌐 Network & Observability

  • 🌍 Socket HTTP/1.1: A lightweight cross-platform server built directly on BSD sockets or Winsock.
  • 📊 Runtime metrics: Inspect pool snapshots, historical peaks, and average, P50, P95, and P99 latency.
  • 🩺 Diagnostic endpoints: Use /api/health, /api/stats, and /api/process to observe the service.

⚙️ Engineering Practice

  • 🛠️ CMake + CTest: Build and run the thread-pool and pool tests with one command.
  • 🔁 Mock/MySQL modes: Learn the complete flow without external dependencies, or connect to MySQL for a real database path.
  • 🚀 One-click setup: Start the MySQL mode on Windows with the included PowerShell script.

🚀 Quick Start

cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
./output/bin/demo_server

The default Mock mode runs without external dependencies. Set CPPPOOLS_DB_MODE=mysql to use the MySQL path.

For detailed information, please check the GitHub repository: https://github.com/jlu005807/CppPools
